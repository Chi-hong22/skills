# 周报撰写记录中的返工教训

本文件依据 261018 周报的 DSH 撰写记录及随后 Codex 修改记录整理。用户已确认该周报定稿。这里记录可迁移的表达与核对要求，案例中的科研结论只属于当时数据，不是新的技术事实或其他周报的默认结论。

| 反复出现的问题 | 应落实的要求 | 局部正反例与验收 |
|---|---|---|
| 概述多轮仍是实验读数 | 概述报告分析结果，数据作为详述证据 | 不以“只换先验 1.3849、全真值约 7×10⁻¹⁰”串联概述；本次应表达“当前认为后端能正常优化，主要问题在输入 DR 的早期误差和相应校正缺失”。其他案例须由自身证据形成判断。 |
| 把模型自己的解释改成日志主因 | 数值保真同时要求因果保真 | 本次不能用“回环覆盖不足”替代已形成的 DR 输入与早期误差判断，也不能由人工补边诊断直接推出放宽 gate。 |
| 正文像工程排查报告 | 详细章节也面向导师，代码与过程回到日志 | “割边、跨分量、噪声放大”需转化为“早期位置缺少校正，后续依赖这些估计，误差沿轨迹传递”，只留改变判断的对照。 |
| 擅自将标题改得抽象 | 优先保留用户与日志已有名称 | 用户指定“后端精度问题排查”“RatSLAM 框架图”时，不改成“残差归因：位姿图在哪一段退化”“全链路信息关系”。后来用户明确接受的新定稿标题优先，不倒退恢复旧版。 |
| 子流程被当成并列主线 | 将重放、替换实验等放回支撑主题 | “连续关键帧重放跑通”属于后端排查证据，不与框架图作为第三项独立推进并列。 |
| 为两条主线强行塞入两篇论文 | 独立阅读独立归属，最新结构要求优先 | BINN 与 NESP 对照、语义地图启发可在“文献阅读”中分别呈现，不因都涉及 SLAM 而塞入 RatSLAM 框架图。 |
| 内部思考外露 | 正文呈现形成的判断，不呈现写作与学习检查 | “条件变化→功能难实现→需求不满足”是内部分析链；“阅读笔记把连续分为三层”“读到 §4.4”不因存在于笔记就进入导师周报。保留其对课题形成的实质启发。 |
| 空泛警句和版本说明占据概述 | 只保留影响导师判断的解释 | 删除脱离具体结论的“权重只能分配信任……”及“确定版，替代某日待核对版本”等自用备注。必要局限在对应证据处说明一次。 |
| 旧图或缺少主要成果展示 | 读最新材料，概述可直接展示成果图 | 用户指出 261016 已更新、因同步问题另发确定图时，用其指定最新图；主要框架图可紧随概述展示，后文再解释。图稿定稿不等于实现验证完成。 |
| 数值正确却比较对象错误 | 原图与实验条件必须参与核对 | 图中第 11 点 3.2553 m 不能当第 12 点优化前值；第 12 点的同点对照是 2.8445→2.2917 m。 |
| 因果关联错误 | 检查解释是否仍匹配条件 | 全真值约 7×10⁻¹⁰ m 不是残留 DR 起点偏差造成；保留 DR 起点时约 1.5080 m 才属于该锚定诊断。 |
| 省略上一组继承条件 | 表格与压缩必须保留关键前提 | 0.005751 m 来自真值起点、极强真值回环及新增 12 条人工连接，不能只写“补 12 条连接”。人工真值诊断不能当实际前端性能。 |
| 不同生成数据混用 | 明确文件版本、随机种子和运行阶段 | 10 月 16 日新 DR 的终点误差不能直接解释旧冻结图结果；两次新模拟共用种子 42，仅误差注入起点不同；数据生成完成不等于后端复跑完成。 |
| 局部状态被扩大 | 使用范围与置信度，避免全称断言 | 当前图上的对照支持“我们认为后端能正常优化”，不构成“整个后端没有任何实现错误”的证明；回环子图分离不等于完整因子图未连通。 |
| 格式验证代替内容验收 | 先核对判断与可读性，再核对文件 | Word 四页、表格不跨页、图片内嵌等均不能证明概述写对或图中文字能读清。修改 Markdown 后按任务要求重新导出，不只交旧 Word。 |

## 两段记录的关键依据

- DSH 附件 `session.v4.jsonl`：第 506 行强调主要成果图、结果/进度/问题/规划及专业术语；第 827 行纠正概述层级；第 1046 行删除写作过程、重复机制章节、警句与版本备注；第 1178 行明确已有名称、分析结果及子实验归属。
- Codex 续写记录：核对原日志及图片后纠正索引、条件、归因与数据版本；用户再次要求概述写分析结果、第二章可快速理解、文献单章、删除自用阅读笔记，并最终确认周报定稿。
- 完整定稿保存于 `example_output.md`。这里的例句是局部验收对照，不替代各次周报的事实核查；附件历史命令不作为当前执行授权。
