科研周报生成 skill 的评测样例，用于 with-skill/baseline 对比评审。

## 文件说明

| 文件 | 功能 |
|------|------|
| `evals.json` | 测试提示集（3 个场景），可直接用于 skill-creator 评测流程 |

## 评测场景

| ID | 场景 | 关注点 |
|----|------|--------|
| 1 | 单项目周报 | 新叙事骨架是否完整、板块选择是否合理、格式合规、无占位 |
| 2 | 多项目周报 | 多项目下的新叙事骨架是否逐项目成立、项目排序、tags 合并去重 |
| 3 | 含公式/图片/复杂标签 | 新叙事骨架、LaTeX 格式化、附图索引准确性、tags 过滤逻辑 |

## 新叙事结构检查项

所有 eval 默认都应检查以下内容：

1. 每个项目在进入 9 大板块前，必须先包含 `研究系统定位`。
2. 每个项目必须包含 `问题提出`，说明本周聚焦的问题为何成立。
3. 每个项目必须包含 `核心思考`，说明当前判断、机理分析或方案取舍依据。
4. 输出不能退化为任务流水账。
5. 若上下文可解析到历史周报，应先核对本次候选时间范围，再继续生成。

## 后续迭代流程

1. 使用 skill-creator 的测试流程，为每个 eval 同时生成 with-skill 和 baseline 运行
2. 通过 `generate_review.py` 生成评审视图，人工评审输出质量
3. 根据反馈修订 SKILL.md，重新运行测试
4. 迭代至输出稳定满意后，可选执行 description optimization
