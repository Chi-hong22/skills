## 评审顺序

1. 判断保真：对象、条件、因果、置信度及下一步均与输入一致；数字正确但解释错误仍失败。
2. 沟通效果：概述表达现在怎么看问题和为什么推进；数据清单不能代替分析。详细章节也须面向导师。
3. 内容归属：既有名称和最新用户要求优先，子实验归回主题，独立阅读不强并，内部笔记不外露。
4. 证据与交付：必要条件、来源、图片选择及状态准确，再检查编号、题注、单位、tags和篇幅。

回归既要比较输出质量，也要保留输入证据边界。可用skill-creator做with-skill/baseline对照；静态校验与抽样试写不等于19场景全部生成通过。报告实际执行范围，不将JSON合法、关键词命中或格式完整当作行为保证。

本轮实际执行记录见 `latest_review.md`，分别列出静态校验、模板函数执行、11—18号试写及未覆盖事项。
