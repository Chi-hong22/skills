# Research Weekly Report Skill

面向导师的科研沟通工具。概述中的结果是分析后形成的认识和判断；实验数据在详述中支撑分析，完整过程由源日志承担。全部正文面向导师，不为个人复盘保留工程细节。

## 2026-10-18 修订

依据 DSH 原撰写记录、Codex 后续纠错与用户确认的最终周报，统一概述、主题归属、判断保真和读者表达；删除数据首句、个人复盘、强制改名和强并文献等冲突引导。更新模板与脚本提示、完整定稿示例、局部正反例和18个评测场景。具体科研结论不写成未来周报的固定答案。

## 2026-10-26 修订

在 10-18 版本上补四条硬约束：概述开头 ≤120 字说明“这是什么事、为什么难”，每个主题首段 ≤40 字定位；只写进展与结果，不写步骤、参数与排期；正文 ≤1500 字、引用块 ≤400 字、全篇 ≤2600 字，超出必须压到位；状态如实，初稿不写定稿。新增 `scripts/check_weekly_report.py` 做字数、小节、状态词、过程叙述与表图编号的机检。10-18 定稿示例形成于硬上限之前，篇幅写法不作基准。

## 使用

先恢复上一份周报范围及实际日志目录，按授权继续；读取嵌入笔记和最新图表，内部形成判断，再写概述与详细章节。既有主题名称优先，文献独立归属，主要成果图可直接在概述展示。范围、图表编号、题注、来源和tags须落实，但格式正确不能替代内容验收。

脚本保留历史CLI默认路径，调用时以实际目录显式提供 `--base-path` 或 `--output`。数据生成、骨架生成、Word导出和科研验证是不同状态，未执行的不声称完成。

检查规则与样例时，以SKILL.md为核心，执行细则见prompt.md，避免在多份文件维护相互冲突的规则。更新任何行为时同步受影响的模板、脚本提示和评测。
