# Research Weekly Report Skill

面向导师的科研沟通工具。概述中的结果是分析后形成的认识和判断；实验数据在详述中支撑分析，完整过程由源日志承担。全部正文面向导师，不为个人复盘保留工程细节。

**更新提醒**：一旦本文件夹有所变化，请更新本文档。

## 修订记录

## 文件说明

### SKILL.md

- **地位**：核心技能定义文件
- **功能**：授权与范围、读者假设与硬约束、判断保真、命名优先级、写作与图表规则、输出结构骨架、资源与验收

### references/prompt.md

- **地位**：执行细则，写前到交付的逐步清单
- **功能**：事实核对、分析提炼、读者表达、交付终检与篇幅口径；与 SKILL.md 冲突时以 SKILL.md 为准

### references/example_output.md

- **地位**：完整定稿案例，不作模板
- **功能**：用户确认的 261018 周报原文，示范分析结果、必要证据与独立文献章；案例数字与结论不跨周报套用，图片相对原 Vault

### references/revision_lessons.md

- **地位**：局部正反例与错误核对
- **功能**：两段撰写记录提炼的概述、术语、归属、笔记外露、数据条件与交付正反例

### references/README.md

- **地位**：参考文件分工清单
- **功能**：各参考文件的地位、读取时机与内容，更新参考文件时同步

### references/obsidian_template.md

- **地位**：可选 Templater 骨架
- **功能**：frontmatter、五节结构与建目录/移动文件脚本；运行前须核实目标日志根目录

### scripts/generate_weekly_report.py

- **地位**：确定性辅助脚本
- **功能**：解析上一份周报时间范围、筛选候选日志、提取 tags、生成与 SKILL.md 对齐的骨架；不生成研究判断

### scripts/check_weekly_report.py

- **地位**：交付前机检脚本
- **功能**：只报机械可判问题——正文/引用块/全篇字数、必填小节、概述科普首段、主题定位句、状态词、过程叙述、表图编号与图片数；零依赖

### scripts/requirements.txt

- **地位**：生成脚本的依赖清单
- **功能**：`pyyaml`、`python-frontmatter`；文案更新未新增依赖

### scripts/README.md

- **地位**：脚本使用说明
- **功能**：两个脚本的参数、检查项、边界与输出骨架说明

### evals/evals.json

- **地位**：评测用例集
- **功能**：19 个自包含场景，覆盖分析判断、事实条件与读者理解

### evals/README.md

- **地位**：评测说明
- **功能**：场景构成、评审顺序与验证边界

### evals/latest_review.md

- **地位**：最近一轮验证记录
- **功能**：实际试写与验证结果、未覆盖范围；其中“18 个场景”是 10-18 版当时的记录

## 使用

先恢复上一份周报范围及实际日志目录，按授权继续；读取嵌入笔记和最新图表，内部形成判断，再写概述与详细章节。既有主题名称优先，文献独立归属，主要成果图可直接在概述展示。范围、图表编号、题注、来源和 tags 须落实，但格式正确不能替代内容验收。

脚本保留历史 CLI 默认路径，调用时以实际目录显式提供 `--base-path` 或 `--output`。数据生成、骨架生成、Word 导出和科研验证是不同状态，未执行的不声称完成。

检查规则与样例时，以 SKILL.md 为核心，执行细则见 prompt.md，避免在多份文件维护相互冲突的规则。更新任何行为时同步受影响的模板、脚本提示和评测。
